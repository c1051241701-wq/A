# 错题本

一个错题管理网页，支持导入题库、病例题、单选/多选答题、自动判分、逐题笔记、口诀本、做题注意和截图文字识别。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `wrongbook`。
2. 把本目录里的以下内容全部上传到仓库根目录：
   - `index.html`
   - `README.md`
   - `.nojekyll`
   - `tesseract/` 文件夹
   - `tessdata/` 文件夹
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 1～2 分钟，访问 `https://你的用户名.github.io/wrongbook/`。

如果仓库名使用 `你的用户名.github.io`，网址会直接是 `https://你的用户名.github.io/`。

## 使用

- 点“导入题目”，支持 JSON、CSV、TXT、Markdown，也支持拖入或粘贴截图。
- 导入弹窗里有“插入普通题模板”和“插入病例题模板”两个按钮，可以直接套用格式。
- 病例题支持“总病例描述 + 多个子问题”的 JSON 或文本格式。
- 截图会先识别成文字，校对后再导入。
- 病例题在列表中带“病例”标签，答题时上方固定显示总病例描述，可以在本病例的上一问/下一问之间切换。
- “口诀本”用于记录自己的记忆线索，支持学科、标签、置顶和搜索。
- “做题注意”用于记录审题、计算和选项里的坑，可以勾选“已注意”、置顶和筛选。
- “备份与恢复”会导出题库、答题记录、笔记、口诀和做题注意；恢复时可选合并或覆盖。
- 答题记录和笔记保存在每个访问者自己的浏览器里，不会上传到服务器。
- 首次使用截图识别时需要加载 OCR 模型；本目录已经包含模型文件，不依赖第三方识别接口。

## 数据备份

页面右上角的“备份与恢复”可以下载 JSON 备份。换浏览器或换设备前，先导出，再在新页面里恢复。
